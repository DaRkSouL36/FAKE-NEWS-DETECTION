## 📘 PROJECT OVERVIEW

THE FAKE DETECTION SYSTEM IS A COMPLETE END-TO-END APPLICATION THAT COMBINES MACHINE LEARNING, NATURAL LANGUAGE PROCESSING, SPEECH INTERACTION, AND MODERN WEB DEVELOPMENT TO TACKLE THE RISING CHALLENGE OF FAKE NEWS. THE SYSTEM ALLOWS USERS TO SUBMIT NEWS ARTICLES VIA TEXT OR SPEECH, SELECT A MACHINE LEARNING MODEL, AND RECEIVE PREDICTIONS ON WHETHER THE ARTICLE IS FAKE OR REAL — ALONG WITH A CONFIDENCE SCORE AND A DYNAMICALLY GENERATED EXPLANATION.

THIS PROJECT FOCUSES ON SCALABILITY, INTERPRETABILITY, ACCESSIBILITY, AND A CLEAN USER EXPERIENCE THROUGH MODULAR DESIGN.

---

## 💬 FEATURES

### AI-POWERED NEWS CLASSIFICATION

- SUPPORTS MULTIPLE MACHINE LEARNING MODELS TRAINED ON KAGGLE-STYLE FAKE NEWS DATASETS.
- MODELS INCLUDE: TF-IDF + LOGISTIC REGRESSION, RANDOM FOREST, SVM, HISTOGRAM GRADIENT BOOSTING, AND MORE.
- USERS CAN SWITCH BETWEEN MODELS USING A DROPDOWN.
- SYSTEM OUTPUTS:
  - **LABEL**: REAL OR FAKE
  - **CONFIDENCE SCORE** (E.G., 94.21%)
- DYNAMIC AI-GENERATED EXPLANATIONS ARE GENERATED THROUGH HUGGING FACE TRANSFORMERS, SUMMARIZING WHY THE NEWS WAS FLAGGED BASED ON KEY TEXTUAL EVIDENCE.
- AFTER MAKING A PREDICTION, THE SYSTEM CALLS THE **MICROSOFT PHI-2** LANGUAGE MODEL TO:
  - PARSE THE ARTICLE.
  - DETECT FACTUAL CLAIMS AND RHETORIC.
  - GENERATE A **HUMAN-READABLE EXPLANATION** SUPPORTING THE PREDICTION WITH CITED TEXTUAL EVIDENCE.

### MODERN & ACCESSIBLE UI

- BUILT USING **JavaScript** AND **CSS** FOR A MODULAR, MAINTAINABLE DESIGN.
- RESPONSIVE AND OPTIMIZED FOR DESKTOP, TABLET, AND MOBILE DEVICES.
- TOGGLE BETWEEN **LIGHT MODE** AND **DARK MODE** WITH LOCAL STORAGE PERSISTENCE.
- WCAG-ACCESSIBLE INTERACTIONS USING:
  - ARIA ATTRIBUTES
  - KEYBOARD NAVIGATION
  - SCREEN READER SUPPORT

## ⚙️ HOW IT WORKS

1. **USER INPUT**  
   USERS ENTER OR DICTATE A NEWS ARTICLE INTO THE WEB INTERFACE. THE SYSTEM ALLOWS FREEFORM TEXT SUBMISSION VIA TYPING OR SPEECH RECOGNITION.

2. **BACKEND ANALYSIS**

   - THE SELECTED ML MODEL IS LOADED VIA FASTAPI.
   - THE INPUT TEXT IS VECTORIZED USING THE ASSOCIATED TF-IDF TRANSFORMER OR EMBEDDINGS.
   - A PREDICTION IS RETURNED IN JSON FORMAT ALONG WITH A CONFIDENCE SCORE.
   - A SECOND ENDPOINT USES TRANSFORMERS TO GENERATE HUMAN-LIKE TEXTUAL EXPLANATIONS FOR THE DECISION.

   - **OPTIONAL**: SYSTEM SPEAKS OUT THE RESULT
   - **FEEDBACK MODAL** ALLOWS USERS TO RATE THE OUTPUT

## 🏁 USAGE

1. **LAUNCH THE WEBSITE**

   - OPEN THE LOCALHOST OR DEPLOYED WEBSITE LINK.

2. **INPUT A NEWS ARTICLE**

   - TYPE OR SPEAK A NEWS HEADLINE / PARAGRAPH USING THE MICROPHONE ICON.

3. **SELECT MODEL (OPTIONAL)**

   - CHOOSE FROM LOGISTIC REGRESSION, SVM, RANDOM FOREST, OR DEEP LEARNING MODELS.

4. **VIEW PREDICTION**

   - SYSTEM DISPLAYS:
     - **PREDICTION:** REAL / FAKE
     - **CONFIDENCE SCORE**
     - **FACTUAL EXPLANATION (LLM-GENERATED)**

5. **GIVE FEEDBACK**
   - CLICK FEEDBACK BUTTON TO RATE THE SYSTEM AND SUBMIT COMMENTS.
   - DATA IS STORED SECURELY IN SUPABASE.
